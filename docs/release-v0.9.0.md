# v0.9.0 —— 词素语义核证 · 防假拆解

> 本版本的核心是**修掉「看起来拆对了、其实是假拆解」的问题**。
> 用户可见的后果举例：查 `сучить`（捻、搓）时，「词族」卡此前显示的是 **`уч-`（教、学）** 的家族 —— 一个与「搓」毫无关系的词根。

**发布日期**：2026-09-16 · **上一版本**：v0.8.0

---

## 一、本次修好了什么

### 1. 词首假词根误拆（v0.9.0 主要工作）

俄语单字符前缀只有 `в-` `о-` `с-` `у-` 四个。引擎此前会把**恰好等于某个前缀字母**的词首字符当成前缀来解释，于是把词根的第一个字母切走，再用剩下的部分去匹配一个语义无关的词根：

| 词 | 含义 | 修复前 | 修复后 |
| --- | --- | --- | --- |
| `сучить` | 捻、搓 | `{уч-@1, -ить@3}`（`уч-`＝教、学） | `{суч-@0, -ить@3}`（空洞 0） |
| `сучок` | 节、枝节 | `{уч-@1, -ок@3}` | `{суч-@0, -ок@3}` |
| `самосуд` | 私刑 | 未正确切出 `суд-` | `{само-@0-4, суд-@4-7}` |
| `доминировать` | 支配 | 未正确切出 `домин-` | `{домин-@0-5, -овать@7-12}` |
| `больной` | 病人 | `боль-` 后无后缀 | `{боль-@0-4, -ной@4-7}`（空洞 0） |
| `однако` | 然而 | `{дн-@1, ...}`（`дн-`＝日、昼） | `{однако-@0-6}` |
| `водопад` | 瀑布 | 曾跳过 `пад` | `{водо-@0-4, пад-@4-7}` |
| `землетрясение` | 地震 | 曾跳过 `ряс` | `{земле-@0-5, тряс-@5-9, -ение@9-13}`（空洞 0） |

`уч-`（教、学）与 `дн-`（日、昼）在词素库里的身份是**词根（root）而非前缀** —— 缺陷的本质是这两个词根被当成「词首可解释片段」放行。

### 2. 实现方式：**只改数据，不改算法**

`packages/core/src/**` **一行未改**。修复方式是在 `packages/data-pipeline/roots_ru.json` 中补齐 **9 条词素**（441 → 450）：

- **6 条真词素**（均附可复核的 ru.wiktionary `{{морфо-ru}}` 来源片段）：`суч-` `суд-` `домин-` `-ной` `пад-` `тряс-`
- **3 条整词抑制条目**（**非语义切分**，`origin` 字段已明确标注）：`столп-` `казус-` `однако-`
  - 它们的作用只是**阻止**错误切分（例如 `столп`（柱）此前被拆成 `стол-`（桌子）），**不代表该词在语义上可拆**

### 3. 顺带修好的

- **`столп` → `стол-`**（柱子 → 桌子）、**`казус` → `каз-`**（事件 → 处决/国库）两处同类型假词根
- 词素库 `morphemes` 由 **909 → 918** 条（俄语 441 → 450）

## 三、⚠ 已知代价与豁免（如实披露）

### 1. `loses = 2`：2 个词由「可拆」变为「不可拆」

`поднаковальня`、`поднакопить` 此前被拆成含假词根 `дн-`（日、昼）的**双重错误拆解**（`по- + дн- + -ко + …`），现返回「不可拆」。

- 定性：`наковальня`（铁砧）的词源是 **ковать（锻造）**，与 `день`（日）无关 ⇒ **由假拆解转为不拆属净改善**
- 但**计量事实必须并存登记**：`loses` 的数值就是 **2**，不因定性为改善而写成 0

### 2. ★ AC-5 豁免：空洞绝对值上升，仅率下降

空洞≥3 的**绝对值上升**（口径A +29 / 口径B +37），**率下降**（−0.4974pp / −0.4315pp）。

- 新词素让 **176 个原本不可拆的词变为可拆**，这些词的残差空洞计入全库总数 ⇒ **率的下降含「分母长大」的机械成分**（可拆数 33,174 → 33,495）
- **本项目旧判据（仅看绝对值）判为不通过；新判据（绝对值 + 率双口径）判为通过** ⇒ 本版本属**豁免放行**
- **v0.10.0 不得沿用同一豁免**

### 3. ★ AC-11(c) 豁免：上升全部源自 `-ной` 一条

留一法实测：口径A/B 的上升**全部来自 `-ной`**（去掉它 ΔA +70 / ΔB +71；其余 7 条全为负）。

**我们选择保留 `-ной`**，理由：剔除它会让 **176 个词由可拆变不可拆**（含 `больной`/`внеземной`/`входной`/`выводной` 等真词）——以正确性换一个被误写的判据，方向错误。

同时认定 **AC-11(c) 的「绝对值」判据存在结构缺陷**：任何「让 N 个不可拆词变为可拆」的词素都**必然推高空洞绝对值**，故该判据在结构上不可满足。v0.10.0 起改为三条：变差 = 0 词 · 空洞变多 = 0 词 · **固定分母下的率不得上升**。

### 4. 仍未消除：`да-` 假族 26 词（**范围决策 · 已知延期缺陷**）

> 口径：范围决策 · 已知延期缺陷（逐词核证假族 **26** 词；`да-` 首片段组共 63 词，另 27 词因库内无词源切分数据无法判定）。

`дав-`/`дар-`/`дал-` 词根被截为 `да-`，例如 `вдавить` 与 `вдаться` 输出**同形**而语义相反。**本轮明确不做**：实测注入 `дав-`/`дар-`/`дал-` 会改判真族 4 词（`вдаваться`/`сдавать`/`сдаваться`/`удаваться`）并破坏两条防回退护栏。需**新机制**，列为 v0.10.0 候选。

### 5. 唯一残留缺陷：`термостат`（恒温器）

`термостат` 仍为 `{термо-@0-5}`（空洞 4），`статика`/`статический`/`астатизм` 仍不可拆。

**试过并否决的方案**：补 `стат-` 词根 —— 唯一收益是 `термостат` 一处，代价是 `экстатический` 由可拆变**不可拆**、`достать` 类词出现词中段假词根、68 个词切分变化。依「正确性 > 覆盖率」原则否决。

## 七、下一版本（v0.10.0）方向

按「正确性 > 覆盖率」优先级：

1. **补 `а-`（否定前缀）** —— 实测 `астатизм`/`астатический`/`астатичность`/`гигростат` 的**正确切分正被拒绝**，且它是重估 `стат-` 的前提
2. **词中空洞的通用上限** —— 替代目前的点状补词素
3. **假词根全库普查** —— `каз-`/`дом-`/`дн-` 的兜底抑制是点状的，同族未枚举的词仍可能误拆
4. **`да-` 假族** —— 需新机制
5. **`термостат`** —— 接 `а-` 后重估 `стат-`，或按 H-d 协议转为常驻留红断言
