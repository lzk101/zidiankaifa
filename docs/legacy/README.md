## ⛔ 三条禁令（依 `DEC-008`，指代按**文件身份**、**不按位置**）

1. **禁止运行** `check_requirements.py`。
   - 原因（**机制性，非风格问题**）：其 `:23 ROOT = os.path.dirname(os.path.abspath(__file__))`，
     `:24-27` 四个写目标全部由 `os.path.join(ROOT, …)` 构造 ⇒ **写目标跟随脚本自身所在目录**；
     `:124 open(SUMMARY, "w")` 会**无条件重写** `需求总结.md` ⇒ 首个牺牲品正是文件头部的
     「⚠️ 已废弃 / ARCHIVED」横幅。**运行一次 = 横幅消失 = 下一个接手者误信错误进度。**
2. **禁止写入 / 覆盖 / 追加 / 删除**上面那 4 个 `.md`。
3. **归档只改变位置，不改变禁令** —— 若这些文件再被移动，禁令**随之成立**。

> ⚠ **注意：改名不等于解除禁令。** 即便把脚本改名成 `*.archived` 之类，**运行它仍被禁止** ——
> 本禁令的对象是**这个脚本的身份**，不是它的文件名或路径。
