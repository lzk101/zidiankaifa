## v0.7.0 词源关联网络 · 同根词族

延续「俄语的词源依旧不足，例如 тоска」的反馈。上一轮建了词根表/词缀表让词能横向展开，
这一轮让**词条页本身**把关联铺开——查一个词就能看到它的词源线索与整个词族。

### 🔗 词源详解里的相关词变可点链接

「继承自原始斯拉夫语 \*tъska，可能与 **тощий** 或 **тискать** 相关」——这两个词现在直接可点，
tooltip 带释义，点击即查。

- **俄语**：西里尔词天然与中文说明区隔，直接提取，几乎零噪声。库内 **58.1%** 的俄语词条
  （27,299 / 46,976 个提及词）能拿到可链接的相关词
- **英语**：只取构词表达（`un- + believe + -able`、`photo- + -graph`）里的成分。
  按全文实词提取会让 `telephone` 抽出 *distance/denoting/apparatus/signals* 共 24 个叙述用词——
  它们在 77 万词库中同样可查，会把详解糊满无效链接
- 正文用长词优先 + 显式前后瞻切分（JS 的 `\b` 不认西里尔）

### 🕸 查词页「同根词 · 词族」

按共享词素分组展示词族，点词素进词根表、点词回查：

- `тоска` → тоск- 组 5 词（тоскливый / тосковать / затосковать / стосковаться / истосковаться）
- `telephone` → tele 组 27 词 + phon 组 30 词
- 剔除裸词素碎片（`phon`/`phon-`/`tele` 这类不再出现）
- 英语按 bnc/frq 词频排序：`tele` 组从字母序的 `telep/teles/teledu/telega` 变为
  `television/telegraph/telecom`；无词频词不占位，词族从 80 词精简到 57 词
- 词缀组限 16 个（词根给满 40）：`рас-` 会带出 `раса/Расти` 噪声，词缀语义关联天然弱于词根

### 🐛 拆解缺陷修复

- **词首间隙假命中**：`сегодня` 曾被拆成 `год- + -ня`（"се" 被跳过，靠 `-ня` 把覆盖率补到 5/7
  骗过 0.55 阈值）。新规则要求词首间隙能被前缀**精确解释**
- 过程中两次踩坑：直接拒绝会误杀 `acknowledge`（`ac-+know+-ledge`，`know` 起于位置 2）；
  放宽为 `startsWith` 又让 `сегодня` 的 "се" 被单字符前缀 `с-` 解释而复发。终版用精确匹配

### 📚 词素库 888 → 909

| 语言 | 新增 |
|---|---|
| 俄语 +9 | `стол-` `брат-` `сад-` `дн-` `пол-` `сказ-` `каз-` `путешеств-` `шеств-` |
| 英语 +12 | 拉丁语同化前缀 `ac- af- ag- al- ap- ar- as- at- col- cor- ef- ir-` |

效果：`рассказать` 由错误的 `рас-+-ка+-ать` 变为 `рас-+сказ-+-ать`，`показать` 补回 `каз-`，
`стол→стол-`、`садовник→сад-+-ник`、`путешествие→путешеств-+-ие`。

自动挖矿已被勘察否掉（从词表挖「完整词形 + 派生词 ≥4」得 2,226 候选，但 `ради` 500 派生全是
радио/радиация/радиус 的巧合——**同前缀 ≠ 同源**），故改为精准补齐。
