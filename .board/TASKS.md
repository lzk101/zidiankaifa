| D5 | 6 | 其中 4 条为 `суч-` 系**假词根**（`сучить`→`уч-` 等），2 条预言性守卫已绿 | ⏸ 范围外（与 D4 同类） |

**★ D1 的范围定义与完成度（关键，防误导）**：
D1 缺陷的完整定义是「**词首 gap=1 且该 gap 字符 ∉ 库内前缀集**」。
在此定义下 **267/267 全部消除（100%）**，并由**四项独立检验**确认：
① 假前缀组 267 → 0；② 自洽性检验泄漏 = 0 词；③ 尺子 A 覆盖独立减少 267 词（与 ① 逐词吻合）；④ AC-4 真前缀组 0 误杀。
**⇒ D1 修复是完整且真实的，不是部分修复。**

**★ 已知残余（如实记录，非本迭代）**：修法后仍有 **75 词**呈「gap=1 但 gap 字符 ∈ {в,о,с,у}」形态，
其首片段分布 = **`да-`×63 / `уч-`×11 / `дн-`×1**。其中：
- `да-`×63（如 `удаваться` = `у + да- + -вать`）—— `да-` 来自 `дать`（给），对 `удаваться` 属**边缘可辩护**（`удача` 确含 `да-` 词源），但会与 `дача/дательный` 词族混同；
- **`уч-`×11（`сучить`/`сучок`/`сучковатый` …）与 `дн-`×1（`однако`）是真假词根污染**，与 D4 同类。

**裁定**：**不扩大本迭代范围**。理由：① 这 75 词**修法前就已可拆**（`gapExplain` 对 gap≥2 早已放行同类），**修法未新增它们**，
非回归；② 消除它们需新增「**词素级相等 + 词源一致性**」判据，属**新机制**而非本 bug 修复；
③ 与 D2/D4/D5 是同一条「词素语义核证」议题，拆开做会碎片化。
⇒ **升为 v0.9.0 的 P0 项，并写入 `ru_morph_defects.mjs` 留红**（红即待办，不得删除断言）。
**⇒ 发布 v0.8.0 时必须在 Release Notes 与 `docs/需求总结.md` §21 如实披露此残余**，不得沉默。
