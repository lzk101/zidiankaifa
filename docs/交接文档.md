| `workspace-write`（受限） | ❌ 阻塞 —— 沙箱禁**带管道 stdio 的 spawn**，而 esbuild 必须用管道与后端进程 IPC |

⇒ 该阻塞**是文件策略所致，不是命令本身的缺陷**。**不要**据旧结论直接让用户代跑；先查当前策略。

### 3.3 v0.9.0 修复（本轮）—— 词素语义核证 · 防假拆解

**用户可见症状**：查 `сучить`（捻、搓）时「词族」卡显示 **`уч-`（教、学）** 的家族；`сучок`、`однако`、`столп`（柱，原拆成 `стол-` 桌子）、`доминировать`、`больной`、`водопад`、`землетрясение` 同类。

- **根因（★ 与 v0.8.0 的「字母级 vs 词素级」表述不同，勿混淆）**：`уч-` 与 `дн-` 在词素库里的身份是**词根（root）**，不是前缀 ⇒ 缺陷本质是**这两个词根被当作「词首可解释片段」放行**，**不存在「词素级前缀判定」可修**。俄语单字符**前缀**只有 `в-` `о-` `с-` `у-` 四个。
- **修复方式：只改数据、不改算法** —— `packages/core/src/**` **一行未改**；在 `packages/data-pipeline/roots_ru.json` 补 **9 条词素**（**441 → 450**）：**6 条真词素**（附 ru.wiktionary `{{морфо-ru}}` 来源：`суч-` `суд-` `домин-` `-ной` `пад-` `тряс-`）＋ **3 条整词抑制兜底**（**非语义切分**，`origin` 已标注并披露：`столп-` `казус-` `однако-`）。
- **效果**：词素 `morphemes` **909 → 918**；全库可拆 **33,174 → 33,495**（+323 gains − 2 loses）；尺子 R **238 = 30.09% → 241 = 30.47%**（**+0.38pp**）；尺子 A **32.7% → 32.99%**；R 内空洞≥3 **134/129 → 132/127**；真前缀组 **75 → 63**（**混合计数**，见 §7-10）；全库 D1 形态计数 **0 → 0**。
- **两项豁免（如实披露）**：① **AC-5** —— 全库空洞≥3 **绝对值上升**（A +29 / B +37）而**率下降**（−0.4974pp / −0.4315pp，分母同时从 33,174 长到 33,495）⇒ 按新判据豁免放行，**v0.10.0 不得沿用**；② **AC-11(c)** —— 上升**全部源自 `-ной` 一条**，剔除它会让 **176 词由可拆变不可拆**（含 `больной` 等真词）⇒ 认定该判据**结构上不可满足**（已由 `DEC-020-R1` 改为「空洞三条式」）。
- **代价**：`loses = 2`（`поднаковальня` / `поднакопить`，旧态含假词根 `дн-`，转为不拆属**净改善**）——**计量值就是 2，不写成 0**。
- **测试**：480 → **506**（+26：新增 `ru_morph_d1guard.mjs` 26 条双向守卫）；`ru_morph_defects.mjs` 23/33 → **55/1**；新增 `ru_morph_semantic.mjs` **44/1**（回归项 0）。
- **未达成的目标**：历史目标「拆解覆盖率 30.8% → **>45%**」经实测**不可达**（零新增只改规则上限 **36.54%**；过审定门的合法候选上限 **33.88%**）⇒ **已由用户拍板正式取消**，本迭代覆盖率**如实交付、不设替代目标**（见 §6-A2）。
- 详见 `docs/release-v0.9.0.md` 与 `docs/需求总结.md` §22。

### 3.4 v0.8.0 修复 —— 词首单字符间隙的假词根误拆（D1）

**用户可见症状**：`плескание`（溅水）的词族卡显示 **`лес-`（森林）** 的 40 个词；同类 `хлестаться`→`лес-`、`анестезия`→`нес-`、`ателье`→`тел-`；全库 101,512 条中 **342 词**呈此形态（**267 误拆 + 75 真前缀**）。

- **根因**：`packages/core/src/db/index.ts` 两道「词首间隙」守卫**恰好都放过 `gap === 1`**（守卫一 `if (parts.length === 1 && parts[0].start === 1) return [];` 要求单片段；守卫二 `if (parts.length && parts[0].start >= 2)` 要求 ≥2）。**覆盖率阈值完全无效**（`плескание` 8/9 = 0.89 ≫ `BREAKDOWN_MIN_COVERAGE = 0.55`）。
- **修复**：一行 `>= 2` → **`>= 1`**。不选「无条件禁止 gap=1」是因为会误杀 `удачный`（`у- + да- + -ный`）。
- **效果**：假前缀组 **267 → 0**（四项独立检验确认，非部分修复）；真前缀组 **75 → 75（0 误杀）**；尺子 R 30.85% → **30.09%**（−0.76pp，退的 6 词全是被消除的假拆解）；尺子 A 33,441 → 33,174（−267）；测试 226 → **480**。
- **遗留**：75 词中 `уч-`×11 + `дн-`×1 为**真假词根污染** ⇒ 已由 **v0.9.0** 解决（见 §3.3）；余 `да-`×63 的**假族 26 词**延期 v0.10.0（需新机制）。
- 详见 `docs/release-v0.8.0.md` 与 `docs/需求总结.md` §21。

`resolveDbPath()` 原先只在 userData 副本不存在时复制内置库，导致装过旧版后**永久读旧库**（用户实测 v0.7.0 仍在读 v0.2.x 的 509MB 旧库，俄语词源/词素均为 0）。已由 `apps/desktop/src/dbmigrate.mjs` 的 `ensureUserDb()` 修复（`size:mtime` 指纹比对换库 + 生词本迁移 + `.bak-<ts>` 备份）。详见 `docs/release-v0.7.1.md` 与 `docs/需求总结.md` §20。

## 7. 已知约束与"非缺陷"清单（避免误判）

1. **截图里卡片空白 ≠ 数据为空**：`ZIDIANKAFA_SHOT` 的 `capturePage` **只截视口**。v0.7.1 排查中曾据此误判「词根词缀拆解」为空，实际拆解卡在词源卡**下方视口外**。用 `browser_snapshot` 或 `ZIDIANKAFA_DUMP` 验证。
2. **俄语模式查英语词显示「未收录」是设计**（v0.2「英俄分离」需求），不是 bug。
3. **中文反查英俄交错**是 auto 模式的刻意设计；用语言切换器可强制隔离。
4. **`COLLATE NOCASE` 对西里尔无效**，俄语专名查询必须走 `caseVariants()`。
5. **不要在 `SCHEMA_SQL` 里给新列写 `CREATE INDEX`**（老库会崩 `no such column`）。
6. **改算法前先建正反例判别集**——本项目在 `breakdownWord` 上连续 4 次调参回退的教训见 `AGENTS.md` 第 4.1 节。
7. **引用任何覆盖率/质量数字必须带尺子口径**（R / A / B 不可互比；空洞有「总数」与「最大单段」两口径）。这是本项目多轮互指错误的根源，已写入 `AGENTS.md` 铁律 7。
8. **测试文件的词库路径必须与 cwd 无关**：`pnpm --filter <pkg> test` 的 cwd 是**包目录**，写成相对路径会崩 `unable to open database file`（`errcode: 14`），而从仓库根直接 `node` 跑却正常 ⇒ **假绿**。新增测试必须两种 cwd 各跑一次（`AGENTS.md` 铁律 6）。
9. **尺子 R 是可被伪造的 KPI**（v0.8.0 裁决十三）：机械补 2 字符片段可达 45.76%，但 **91.9% 的增益来自 2 字符片段**，会造出 `безаварийный → без- + ва- + -ный`（空洞 4）这类空心骨架 ⇒ **R 不得单独使用**，必须与质量守卫（空洞口径A/B）同看。
10. **`loses`（可拆→不可拆的集合差分）不等于回归**：`антияпонский` 从碎片式变完整拆解也会被记成 "lost" ⇒ 判真实回归**必须逐词比对 `parts`**。同时**计量值不因定性为改善而改写**（v0.9.0 的 `loses` 是 **2**，即使那 2 个词是净改善）。
11. **「63 词真前缀组」是混合计数** = 真族 10 + 假族 26 + 27 词不可判定（库内无 `chain[].parts`）⇒ **不得读作「63 词全部正确」**；它作为**守卫地板**有效，**不作为正确性证据**。
12. **`да-` 假族的表述口径（逐字，禁用「边缘可辩护」与「≥N」）**：「**范围决策 · 已知延期缺陷（T20 逐词核证假族 26 词；`da-` 首片段组共 63 词，另 27 词因库内无 `chain[].parts` 无法判定）**」。
13. **UI 内嵌版本号**：`apps/web/dist` 是构建产物。v0.8.0 曾因文件策略未重建而显示 v0.7.1（**已闭环**）；今后若 build 被阻塞，Release Notes 必须披露版本号滞后。
