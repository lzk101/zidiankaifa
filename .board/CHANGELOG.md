## 已发布版本

### v0.8.0 — 修复词首 gap=1 假词根误拆（D1）
- **主题**：用户可见症状 **`плескание`（溅水）的词族卡挂到 `лес-`（森林）40 词**；同类 `хлестаться`→`лес-`、`анестезия`→`нес-`、`ателье`→`тел-`，全库 **342 词**呈此形态（**267 误拆 + 75 真前缀**）
- **根因**：`packages/core/src/db/index.ts` 两道守卫恰好都放过 `gap===1`（`parts.length === 1 && parts[0].start === 1` 要求单片段；`parts[0].start >= 2` 要求 ≥2）；**覆盖率阈值完全无效**（`плескание` 覆盖率 0.89 ≫ `BREAKDOWN_MIN_COVERAGE = 0.55`）
- **修复**：`>= 2` → **`>= 1`**（不选「无条件禁止 gap=1」是因为会误杀 `удачный = у- + да- + -ный`）
- **关键数字**：假前缀组 **267 → 0**（四项独立检验确认，非部分修复）；真前缀组 **75 → 75（0 误杀）**；尺子 R **30.85% → 30.09%**（238/791，**−0.76pp**，退的 6 词全是被消除的假拆解 = **预期代价**）；尺子 A **33,441 → 33,174**（−267）；L4 空洞≥3 **134 持平**；测试 **226 → 480**（新增 `ru_morph.mjs` 60 + `ru_morph_d1fix.mjs` 194）
- **同时闭环**：**C1**（补跑 `pnpm --filter @zidiankaifa/sync-server build`，`/health` 返回 `0.8.0`）、**DEC-009**（`measure_ru_breakdown.mjs` 的 import 路径修复）
- **发布形态**：tag `v0.8.0` ⇒ commit `4c89272`；**仅源码、0 附件**——`apps/web/dist` 未重建（受限沙箱禁管道 stdio），**UI 关于页仍显示 v0.7.1**，已在 Release Notes 披露
- **遗留（已披露）**：75 词「真前缀 gap」形态中 `уч-`×11 + `дн-`×1 为**真假词根污染**，升为 v0.9.0 P0（即本文件上方待发布的 V9-2）
- **详情**：`docs/release-v0.8.0.md`、`docs/需求总结.md` §21
- **发布结果**：✅ 已发（**0 附件**）
