### 3.3 v0.8.0 修复（本轮）

**词首单字符间隙的假词根误拆（词族卡污染）**：查 `плескание`（溅水）时「词族」卡显示 **`лес-`（森林）** 的 40 个词。同类污染 `хлестаться`→`лес-`、`анестезия`→`нес-`、`ателье`→`тел-`（各 40 词）；全库 101,512 条中 **342 词**呈此形态（**267 误拆 + 75 真前缀**）。

- **根因**：`packages/core/src/db/index.ts` 两道「词首间隙」守卫恰好**都放过 `gap === 1`**——守卫一 `if (parts.length === 1 && parts[0].start === 1) return [];`（:846）要求单片段，而 `плескание` 拆出 3 段；守卫二 `if (parts.length && parts[0].start >= 2)` 要求 ≥2。**覆盖率阈值完全无效**（`зверство` 8/8 = 1.00、`плескание` 8/9 = 0.89 ≫ 0.55）。
- **修复**：一行 `>= 2` → **`>= 1`**（只做字母级判定，不做词素级）。不选「无条件禁止 gap=1」是因为会误杀 `удачный`（`у- + да- + -ный`，词源 `удача`）。
- **效果**：尺子 R 244/791 = **30.85% → 238/791 = 30.09%**（−0.76pp，退的 6 词全是被消除的假拆解，**属预期代价**）；尺子 A 33,441 → **33,174**（−267 词）；全库 D1 假前缀组 **267 → 0**、真前缀组 **75 → 75（0 误杀）**、新增拆解 **0**；L4 空洞≥3 冻结值 **134 持平**。
- **测试**：226 → **480**（+254），全部通过。
- 详见 `docs/release-v0.8.0.md` 与 `docs/需求总结.md` §21。**残余 75 词已如实披露**，见 §6-A2。

### 3.4 v0.7.1 修复

**桌面端升级不换库**：`resolveDbPath()` 原先只在 userData 副本不存在时复制内置库，导致装过旧版后**永久读旧库**（用户实测 v0.7.0 仍在读 v0.2.x 的 509MB 旧库，俄语词源/词素均为 0）。已由 `apps/desktop/src/dbmigrate.mjs` 的 `ensureUserDb()` 修复（指纹比对换库 + 生词本迁移 + 备份）。详见 `docs/release-v0.7.1.md` 与 `docs/需求总结.md` §20。

## 7. 已知约束与"非缺陷"清单（避免误判）

1. **截图里卡片空白 ≠ 数据为空**：`ZIDIANKAFA_SHOT` 的 `capturePage` **只截视口**。v0.7.1 排查中曾据此误判「词根词缀拆解」为空，实际拆解卡在词源卡**下方视口外**。用 `browser_snapshot` 或 `ZIDIANKAFA_DUMP` 验证。
2. **俄语模式查英语词显示「未收录」是设计**（v0.2「英俄分离」需求），不是 bug。
3. **中文反查英俄交错**是 auto 模式的刻意设计；用语言切换器可强制隔离。
4. **`COLLATE NOCASE` 对西里尔无效**，俄语专名查询必须走 `caseVariants()`。
5. **不要在 `SCHEMA_SQL` 里给新列写 `CREATE INDEX`**（老库会崩 `no such column`）。
6. **改算法前先建正反例判别集**——本项目在 `breakdownWord` 上连续 4 次调参回退的教训见 `AGENTS.md` 第 4.1 节。
7. **引用任何覆盖率/质量数字必须带尺子口径**（R / A / B 不可互比；空洞有「总数」与「最大单段」两口径）。这是本项目多轮互指错误的根源，已写入 `AGENTS.md` 铁律 7。
8. **测试文件的词库路径必须与 cwd 无关**：`pnpm --filter <pkg> test` 的 cwd 是**包目录**，写成相对路径会崩 `unable to open database file`（`errcode: 14`），而从仓库根直接 `node` 跑却正常 ⇒ **假绿**。新增测试必须两种 cwd 各跑一次（`AGENTS.md` 铁律 6）。
9. **UI 显示的版本号可能滞后于代码**：`apps/web/dist` 是构建产物，v0.8.0 未重建（见 §6-D）⇒ 关于页显示 v0.7.1 不代表 core/桌面端是 v0.7.1。
